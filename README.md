#Installing WiiDesk

To install WiiDesk run WiiDesk Setup 1.0.0.exe

It will install and WiiDesk Shortcut will appear in your desktop

A bat file will also appear for turning on/off WiiDesk AutoLaunch

AutoLaunch WiiDesk

To enable/disable launching for WiiDesk run toggle.bat

it does the same thing double click on double click again off

Close WiiDesk app

To close WiiDesk and revive your desktop on your keyboard press

Ctrl+Shift+Esc

This will open Task Manager look for WiiDesk right click and End task

and your channel is deleted (IT CANNOT BE UNDONE SO BE CAREFUL)

editing a channel same thing hover over a channel there is a blue
pencil icon click it

You can move a channel in 2 ways

Method 1

Hover over a channel and there are arrows left and right if you
choose left or right the channel will move one slot in that direction

Method 2 (Recommended)

Drag the channel in Channel Manager and drag it to a existing channel
both channels will change places

If you want to reset everything back to normal (CANNOT BE UNDONE)
